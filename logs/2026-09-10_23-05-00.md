# 2026-09-10 23:05 - Visual redesign: cuero, tipografía, paleta

## Indicación
4 mejoras visuales: flip más lento, borde de cuero, tipografía elegante, fix paleta de colores.

## Cambios realizados

### 1. Flip animation más lento
- `flippingTime`: 500ms → 800ms en HTMLFlipBook
- `maxShadowOpacity`: 0.4 → 0.5 (sombra más pronunciada)

### 2. Borde de contenedor de cuero (FlipBookViewer)
- Contenedor HTMLFlipBook envuelto en div con:
  - Gradiente marrón cuero (`#3d2b1f` → `#2a1c12` → `#1f150d`)
  - Sombra interior simulando costura (dashed border)
  - Sombra de lomo izquierdo (spine shadow)
  - Box-shadow exterior para profundidad
- Background general: gradiente oscuro cálido (`#1a1008`)
- Toolbar: mismos tonos marrones, botones con `rgba(80,50,20,0.5)`

### 3. Tipografía elegante
- Google Fonts: **Cormorant Garamond** (serif display) + **Inter** (body)
- `--font-display` para títulos (títulos de libro, marcadores, header)
- `--font-body` para UI general
- Clases `.font-display` y `.font-body` disponibles

### 4. Fix paleta de colores
- **Problema**: ColorPalette seteaba CSS variables (`--bg`, `--card`, `--text`, `--accent`) pero la app usaba clases `dark:` de Tailwind que no leen esas variables
- **Solución**: Reemplazadas todas las clases `dark:bg-*`, `dark:text-*`, `bg-gray-*` por `style={{ backgroundColor: 'var(--bg)' }}` etc.
- Archivos actualizados: App.tsx, Library.tsx, FlipBookViewer.tsx, index.css
- Body ahora lee `var(--bg)` directamente
