# 2026-09-10 22:51 - Optimización de inputs para gama baja

## Indicación
Optimizar inputs de zoom y página en FlipBookViewer para dispositivos de gama baja (APK Android).

## Cambios realizados

### Inputs (líneas 224-268)
- Cambiado `type="number"` a `type="text"` + `inputMode="numeric"` en ambos inputs
  - Elimina spin buttons nativos que causan re-renders
  - Mantiene teclado numérico nativo en Android
- Eliminado debounce de 300ms en zoom onChange — ahora es inmediato
- Filtro `replace(/[^0-9]/g, '')` para solo aceptar números
- Enter cierra el teclado (`blur()`) antes de aplicar
- Eliminadas clases CSS innecesarias (`[appearance:textfield]`, `::-webkit-*-spin-button`)

### Memoria (blob URLs)
- Cache de blob URLs en `useRef<Map>` para evitar crear URLs duplicadas
- Cleanup en unmount: `URL.revokeObjectURL()` para todas las URLs

### Rendimiento
- Resize listener optimizado con `requestAnimationFrame` throttle
- Keyboard listener ya no se re-registra en cada cambio de `zoom` (usa `zoomRef`)
- Eliminado `zoomTimer` ref (ya no se usa debounce)

## Archivos modificados
- `web/src/components/FlipBookViewer/FlipBookViewer.tsx`

## Build
- `npm run build` exitoso (1.17s)

## Nota post-build
- El caché de blob URLs (`useRef<Map>`) rompió el renderizado de `react-pageflip` — revertido
- Se mantienen las optimizaciones de inputs, resize throttle y keyboard ref
