# FLIPPDF - Inicio del proyecto

## Indicación del usuario
Replicar lo que hace FlipHTML5: app Android que convierte PDF/DOCX/PPTX/Imágenes a flipbooks con efecto de giro realista, editor básico, lectura offline. Todo client-side, costo cero.

## Decisiones tomadas
- Stack: Vite + React + TypeScript + Tailwind CSS + Capacitor v6
- Conversión: 100% client-side (pdf.js, mammoth.js, JSZip)
- Flipbook: StPageFlip (page-flip)
- Almacenamiento: IndexedDB via localforage
- Desarrollo: Web primero → APK via GitHub Actions
- Editor: Básico (portada personalizable + elementos multimedia)
