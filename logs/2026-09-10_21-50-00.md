# FLIPPDF - Fase 2: Conversor de archivos

## Indicación del usuario
Integrar los convertidores (PDF, DOCX, PPTX, imágenes) con UI de upload y flujo completo.

## Cambios realizados
- `components/FileUploader/FileUploader.tsx` - Drag & drop + click para seleccionar
- `components/Converter/useConverter.ts` - Hook que orquesta la conversión según formato
- `components/Converter/ProgressBar.tsx` - Barra de progreso con porcentaje
- `App.tsx` - Flujo: Upload → Conversión → Confirmación
- Dependencia `html2canvas` instalada

## Formatos soportados
- PDF → imágenes via pdf.js (renderiza cada página a canvas)
- DOCX → HTML → imágenes via mammoth + html2canvas
- PPTX → extrae imágenes embebidas via JSZip
- Imágenes (JPG/PNG/WebP/GIF) → convierte a WebP unificado
