# FLIPPDF - Fase 8: Deploy GitHub Pages

## Indicación del usuario
Configurar deploy a GitHub Pages para testing web.

## Cambios realizados
- `.github/workflows/deploy-pages.yml` - Workflow de deploy:
  - Build la app web
  - Deploy a GitHub Pages
- `.gitignore` - Archivos ignorados por git

## Para activar GitHub Pages
1. Ir a Settings > Pages del repositorio
2. Seleccionar "GitHub Actions" como source
3. El workflow se ejecutará automáticamente al hacer push a main

## URL de testing
Una vez activado, la app estará disponible en:
`https://<usuario>.github.io/<nombre-repo>/`
