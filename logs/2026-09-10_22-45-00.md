## Cambios realizados

  - Checkout del código
  - Setup Node.js 20, Java 17, Android SDK
  - Instalación de dependencias
  - Build de la app web
  - Agregar plataforma Android (cap add)
  - Sincronizar Capacitor
  - Build APK con Gradle

- `README.md` - Documentación completa del proyecto

## Flujo del workflow
1. Se ejecuta al hacer push a `main` o manualmente
2. Instala todas las dependencias
3. Build la app web
4. Agrega Android via Capacitor
5. Build el APK debug
6. Crea una Release en GitHub con el APK adjunto

## Requisitos para usar
- Crear repositorio en GitHub
- Subir el código (el workflow se ejecuta automáticamente)
- La Release se crea con tag basado en la versión de package.json
